API

Plain JSON and CSV files. No key, no sign-up, no rate limit. Copy a link and use it.

    Updates
    Twice a day (09:00 and 13:00 EAT). BOT publishes once per trading day; weekends repeat Friday.
    Units
    TZS per 1 unit of foreign currency. Gold is per troy ounce.
    History
    24 June 1999 to today, one file per year or per currency.
    Reliability
    If BOT changes its page or sends odd numbers, the update stops instead of publishing bad data.
